记账本

一个轻量级的个人收支记录网页应用，基于原生 HTML / CSS / JavaScript 开发，无需后端，打开浏览器即可使用。

✨ 项目简介

这是一个用来随手记录日常收支的小工具。页面支持记录收入与支出，自动计算总金额，数据保存在浏览器本地，刷新或关闭网页都不会丢失。

🎮 主要功能

记录收支：支持选择“支出”或“收入”，输入金额和备注，一键添加。
实时统计：自动汇总当前总收入、总支出和结余。
记录列表：清晰展示每一笔账目，支持删除单条记录。
本地存储：使用浏览器 `localStorage` 保存数据，无需注册登录，隐私安全。
响应式布局：桌面端与手机端均可正常使用。

🛠️ 技术栈

- HTML5
- CSS3（Flexbox / Grid、CSS 变量）
- 原生 JavaScript（DOM 操作、事件处理、localStorage）

 🚀 如何运行

1. 下载本仓库中的 `记账本.html` 文件。
2. 用浏览器（Chrome / Edge / Safari）直接双击打开即可。
3. 推荐使用 VS Code 的 Live Server 插件运行，方便边改边看。

📱 使用说明

1. 点击“支出”或“收入”按钮切换记录类型。
2. 输入金额和备注，点击添加按钮即可完成一笔记录。
3. 页面顶部会自动显示当前的结余与总计。
4. 点击记录旁的删除按钮，可以移除不需要的账目。
